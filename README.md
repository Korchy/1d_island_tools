# 1D Island Tools

Blender add-on.

Add-on functionality
-
Creates list of mesh islands for further working with them.

Create Islands db - creates islands structure from active mesh.
Dec Selection - decrease selection, stay selected only whole selected islands.
Select by Count - get number of vertices from whole selected islands and select all other non-selected islands with the same vertices amount.

Blender version
-
2.79
