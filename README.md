# 1D Island Tools

Blender add-on.

Add-on functionality
-
Creates list of mesh islands for further working with them.

Create DB / Free DB - creates/releases islands structure from active mesh.

Dec Selection - decrease selection, stay selected only whole selected islands.

Islands by Verts Amount - get number of vertices from whole selected islands and select all other non-selected islands with the same vertices amount. Partially selected islands - deselects.
